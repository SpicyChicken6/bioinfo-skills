# Over Representation Analysis

## Quick Start

Use `scripts/run_ora.py` for reproducible ORA. It reads foreground gene lists, fetches MSigDB gene sets with `gseapy.Msigdb().get_gmt(category=..., dbver=...)`, runs offline `gseapy.enrich(...)`, and writes tables, a summary JSON file, and compact pathway plots.

Install dependencies in the active analysis environment if needed:

```bash
python -m pip install gseapy pandas matplotlib
```

Typical human Hallmark plus Reactome run:

```bash
python scripts/run_ora.py \
  --genes deg_genes.txt \
  --background expressed_genes.txt \
  --species human \
  --category h.all \
  --category c2.cp.reactome \
  --outdir ora_results
```

Paired up/down contrast plot with back-to-back pathway bars:

```bash
python scripts/run_ora.py \
  --up-genes patient_up.txt \
  --down-genes patient_down.txt \
  --background expressed_genes.txt \
  --species human \
  --category h.all \
  --category c2.cp.reactome \
  --contrast-label patient_vs_control \
  --negative-label Control \
  --positive-label Patient \
  --top 10 \
  --plot-dpi 300 \
  --plot-threshold 0.05 \
  --outdir ora_patient_vs_control
```

Mouse Hallmark run using the latest mouse MSigDB version GSEApy can list:

```bash
python scripts/run_ora.py \
  --genes cluster_markers.tsv \
  --gene-column gene \
  --background detected_genes.tsv \
  --background-column gene \
  --species mouse \
  --category mh.all \
  --outdir mouse_marker_ora
```

List available MSigDB versions or categories:

```bash
python scripts/run_ora.py --list-dbver
python scripts/run_ora.py --species human --dbver latest --list-categories
```

## Workflow

1. Confirm this is ORA: the input should be an unranked foreground list. If the user has ranked statistics and wants rank-aware analysis, use preranked GSEA instead.
2. Gather or infer `species`, MSigDB `category`, and `dbver`. Default to `human`, `h.all`, and `latest`; for mouse default to `mh.all`.
3. Ask for the experimental background when it matters. Prefer all genes that were measured, expressed, or tested. If unavailable, state that GSEApy will use the union of selected gene sets as the background.
4. Match identifiers before running. Offline ORA is case-sensitive; foreground, background, and MSigDB GMT identifiers must use the same identifier type and case. The helper defaults to uppercasing human symbols and preserving mouse symbols.
5. For one foreground list, run with `--genes`. For a contrast with up- and down-regulated gene lists, run with `--up-genes` and `--down-genes`; this writes signed back-to-back pathway plots per MSigDB category.
6. Inspect `summary.json`, `ora_results.tsv`, `ora_significant.tsv`, and the plot files. For paired mode, positive bars are `--up-genes` and negative bars are `--down-genes`.
7. Report results with the MSigDB version/category, foreground size, background definition, adjusted p-value threshold, and leading overlap genes for the top terms.

## Outputs

The helper writes:

- `ora_results.tsv` and `ora_results.csv`: all enrichment results across categories.
- `ora_significant.tsv`: terms with `Adjusted P-value <= --cutoff`.
- `summary.json`: parameters, counts, output paths, and top terms.
- `top_terms.png` and `top_terms.pdf`: top terms by `-log10(adjusted p-value)`, unless `--no-plot` is set. PNG plots default to 300 DPI; change with `--plot-dpi`. PDF companion plots are generated by default for vector-quality text and shapes; skip with `--no-pdf`.
- `ora_<contrast>_combined_<category>_top.png`: paired up/down `-log10(p)` pathway plot when both `--up-genes` and `--down-genes` are supplied. Positive bars use coral, negative bars use soft cyan, pathway labels use a visible left y-axis with ticks, the central zero line is kept, labels sit above the arrows, and gridlines are explicitly disabled. The x-axis label includes the threshold, for example `-log10(p) (p>0.05)`, and unlabeled dashed vertical guide lines mark that threshold on both sides.
- `ora_<contrast>_combined_<category>_top.pdf`: vector PDF companion for the paired pathway plot, generated by default.
- `ora_<contrast>_up_<category>_top.png` or `ora_<contrast>_down_<category>_top.png`: one-sided pathway plot when only one direction is supplied.

## Interpretation Notes

Use adjusted p-values/FDR for claims. Treat odds ratio and overlap genes as effect/context, not as the primary significance control.

Mention when multiple MSigDB categories were tested together. The script preserves per-category GSEApy FDR values; if a strict global correction across all categories is required, recompute it from the combined p-values before making a strong claim.

Do not overinterpret broad terms driven by housekeeping genes, cell cycle, ribosome, mitochondrial, or immune signatures without checking whether those genes reflect the experiment, sample composition, or background choice.
