# GSEApy MSigDB ORA Reference

## Core APIs

GSEApy exposes MSigDB retrieval via:

```python
from gseapy import Msigdb

msig = Msigdb()
gmt = msig.get_gmt(category="h.all", dbver="2024.1.Hs")
versions = msig.list_dbver()
categories = msig.list_category(dbver="2024.1.Hs")
```

Run offline ORA with:

```python
import gseapy as gp

enr = gp.enrich(
    gene_list=foreground_genes,
    gene_sets=gmt,
    background=background_genes,
    outdir=None,
    no_plot=True,
)
results = enr.results
```

Use `gp.enrichr(...)` only when the user specifically wants Enrichr web-service libraries or online Enrichr scoring. For MSigDB GMT dictionaries and explicit backgrounds, prefer `gp.enrich(...)`.

## Background Rules

GSEApy's offline ORA uses all genes in the supplied gene sets when `background=None`. Prefer a user-provided background gene list from the experiment, such as expressed RNA-seq genes, detected single-cell genes, or all genes tested for differential expression.

Other supported background forms are an integer total universe size or a BioMart dataset name such as `hsapiens_gene_ensembl`, but both need caveats. A numeric universe assumes all pathway genes are part of the possible background. A BioMart background uses annotated genes and may not match the assay's tested universe.

## Paired Up/Down Plots

Use paired mode when the user has separate up- and down-regulated gene lists for the same contrast:

```bash
python scripts/run_ora.py \
  --up-genes up_genes.txt \
  --down-genes down_genes.txt \
  --background tested_genes.txt \
  --category h.all \
  --contrast-label patient_vs_control \
  --negative-label Control \
  --positive-label Patient \
  --top 10 \
  --plot-dpi 300 \
  --plot-threshold 0.05
```

The script runs ORA independently for each direction and category, then writes a paired horizontal bar plot per category. Positive coral bars show pathways enriched in `--up-genes`; negative soft-cyan bars show pathways enriched in `--down-genes`. Pathway names are labeled on a visible left y-axis with tick marks, and the central zero line is kept as the direction split. The x-axis uses concise labels such as `-log10(p) (p>0.05)` by default; pass `--plot-column "Adjusted P-value"` to plot FDR as `-log10(adj. p) (threshold=0.05)`. Unlabeled dashed vertical guide lines mark `--plot-threshold`, defaulting to `p=0.05` (`-log10(p)=1.30`), on both sides of paired plots. PNG plots default to 300 DPI, while PDF companion plots are generated by default for vector-quality text and shapes. Use `--no-pdf` only when PDF output is not wanted. Plot backgrounds should stay clean because the helper explicitly disables x/y gridlines.

## Identifier Matching

Offline ORA is case-sensitive. Match the foreground list, background list, and MSigDB gene sets:

- Human MSigDB gene symbols are usually uppercase; uppercasing human symbols is usually safe.
- Mouse symbols from mouse MSigDB are mixed/title case; preserve case unless the source data is known to need conversion.
- Do not mix Ensembl IDs, Entrez IDs, and gene symbols without conversion.

## Common MSigDB Categories

Common human categories include:

- `h.all`: Hallmark
- `c2.cp.reactome`: Reactome curated pathways
- `c2.cp.kegg`: KEGG curated pathways when present for the selected version
- `c5.go.bp`: Gene Ontology biological process
- `c5.go.mf`: Gene Ontology molecular function
- `c5.go.cc`: Gene Ontology cellular component

Mouse category names often use `m` prefixes, for example `mh.all` for mouse Hallmark. Always check available categories with `Msigdb().list_category(dbver=...)` because MSigDB category names can vary by release and species.
