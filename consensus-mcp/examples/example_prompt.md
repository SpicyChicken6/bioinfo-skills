# Example request

Use the consensus-mcp skill to verify my connection and repair expired OAuth for
my client. Find human systematic reviews, meta-analyses, and randomized controlled
trials since 2020 on exercise interventions for depression. Exclude preprints,
cite returned papers, and distinguish direct findings from interpretation.

## Read methods beyond the abstract

Use Consensus to find how DESeq2 estimates and shrinks dispersion. Request
full-text excerpts, keep each passage with its paper citation and section, and
distinguish body-text details from abstract-only evidence. If equations or figures
are missing, say so and follow the source paper rather than reconstructing them.

## API-key fallback

If the Consensus MCP connection fails, use the skill's REST helper with my locally
configured API key. Retrieve three papers about the DESeq2 dispersion method and
check that at least one excerpt contains details beyond its abstract. Report
authentication or plan restrictions rather than silently falling back to abstracts.
