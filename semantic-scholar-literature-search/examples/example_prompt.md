# Example prompt

Use the semantic-scholar-literature-search skill.

Search Semantic Scholar for papers about knowledge-graph and protein-language-model approaches for digenic or oligogenic rare disease prediction.

Requirements:

- Prioritize papers from 2020 onward.
- Include method papers, benchmark papers, review papers, and useful datasets.
- Use Semantic Scholar API metadata rather than free-form web search when possible.
- Export raw results as JSONL.
- Export a paper table as CSV.
- Create a Markdown literature summary.
- Include title, year, venue, citation count, URL, abstract summary, and why each paper is relevant.
- Suggest positive seed papers for recommendation search.
- Clearly state limitations, especially missing abstracts or unavailable full text.

Suggested queries:

- digenic disease prediction knowledge graph
- oligogenic disease gene pair prioritization
- rare disease diagnosis knowledge graph
- protein language model variant prioritization
- gene disease association graph neural network rare disease
