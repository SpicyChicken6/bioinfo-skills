# Development

1. If the brief is missing or unclear, ask focused questions about the goal,
   users, main workflow, and constraints before recommending a stack.
2. Apply the [development rules](assets/AGENTS.md) during setup and adapt these
   templates to the project:
   - [AGENTS.md](assets/AGENTS.md) → `AGENTS.md`
   - [README.md](assets/README.md) → `README.md`
   - [Project layout](assets/project-layout.md) → `docs/project-layout.md`
   - [DESIGN.md](assets/DESIGN.md) → `DESIGN.md`, for web UI projects
3. Create `docs/workflow.yaml` and its preview using the
   [workflow reference](references/workflow.md).
4. Implement the requested scope; leave future plan items pending.
